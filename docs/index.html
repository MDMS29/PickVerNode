The problem

Every project wants a different Node version. Switching means opening a terminal, remembering whether it is nvm use, fnm default, volta install node@ or asdf set, and then reopening every terminal you had.

PickVerNode is not a version manager. It is a remote control for the one you already have.

What it does

See the active version

A status bar item, always visible. One click opens everything.

Switch without a terminal

Pick from the installed versions. The extension runs your manager's own command.

Install & uninstall

Type 20.18.0, 20, lts or latest. Validated against nodejs.org before installing.

Pin it with .nvmrc

Write the current version to .nvmrc so the rest of the team gets it too.
